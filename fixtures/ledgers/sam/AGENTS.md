# Sam Okafor — fictional policy

Every name, amount, date and event is invented. Sam moved from GBP accounts to EUR accounts in July 2026. Preserve both currencies without converting totals. Keep evidence, search for duplicates, balance postings and use the shared ledger lock. Run verification from the application with LEDGER_DIR set to this directory.

## Varying recurring rules and bills

A varying rule's postings hold the median of its last three payments. Save an
unpaid bill on the rule with its evidence; add an expense only when it is paid.
Retain amount-check doubts and require explicit acceptance of unusual amounts.

# Sam Okafor — fictional personal rules

Every value here is invented. This ledger follows the application's general
bookkeeping policy, `policy/BOOKKEEPING.md`; only Sam's own rules are kept here.

## Personal rules

- Sam moved from GBP to EUR in July. New spending uses the Birken accounts in EUR;
  the Bramble accounts keep their GBP history.

## Rebuild and verify

Run verification from the application with `LEDGER_DIR` set to this directory.
